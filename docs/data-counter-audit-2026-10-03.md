## Superseded by return-cost accounting, analysis version 4

The administrator selected a wallet-local same-mint FIFO return convention: outbound lots retain cost in transit; later incoming units restore those lots, up to the outstanding quantity. Excess inflow remains unknown-cost inventory. This convention does not assert ownership of the intermediate wallet. Both position and journey engines now use this rule. Transfers alone never realize profit. Separate new purchase cycles remain distinct while older outbound lots await return.

Durable per-wallet transaction counts are mirrored in wallets.transaction_count with an exact flag, as well as wallet_sync_state.transactions_scanned. Page receipts prevent the same page from committing twice. Counters and event facts commit atomically; incremental overlap is excluded from indexed counts. Legacy signature-only recounts are queued with persisted progress and bounded by the original indexed newest/oldest signatures. Recovery does not scan beyond the saved history or charge user credits. Recounts validate snapshot boundaries before committing. Data sums these persisted per-wallet totals; no multiplication of RPC pages is used.
